## Project Overview

Centrifugation is a critical step in numerous experimental assays in biotech and pharmaceutical research. While benchtop centrifuges are cost-effective (~$1k), they require manual loading and unloading of microplates. Automated centrifuges streamline workflows but cost approximately $60,000 per unit—a significant barrier for smaller organizations.

This MQP aimed to develop an affordable robotic system that works with an existing SCARA-type collaborative robot arm to automate the loading and unloading of microplates in conventional benchtop centrifuges.

## Project Scope

The team designed and built a device that:
- Moves plates between a loading nest and the centrifuge rotor
- Activates and deactivates the centrifuge
- Provides a user-friendly API in C# and Python with simple commands ("load", "unload", "spin")
- Detects and reports centrifuge imbalances
- Ensures safety through hardware and software safeguards
- Includes comprehensive documentation (BOM, assembly instructions, API reference)
